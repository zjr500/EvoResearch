# EvoResearch 前端数据接入说明

已经配置请求的页面包括知识库、实验过程、指标图表、预警与终止。知识库从张嘉荣的接口取数据，实验过程和指标从马雨瑶的接口取数据，预警规则接口归胡语晨的界面子系统。导航还设有实验提交和知识图谱两个预留页面。

## 1. 页面上显示什么

| 功能 | 页面内容 | 请求接口 | 读取的字段 |
| --- | --- | --- | --- |
| F4 知识库 | 标题、类型、创建时间、搜索、翻页 | `GET /kb/entries` | `data.entries[]`、`data.nextCursor` |
| F4 知识库 | 来源和结构化正文 | `GET /kb/entries/{id}` | `document_id`、`source_type`、`source_id`、`content` |
| F4 知识库 | 标题、备注的编辑表单 | `PUT /kb/entries/{id}` | 发送 `title`、变更的 `user_note` 和幂等键 |
| F4 知识库 | 删除条目 | `DELETE /kb/entries/{id}` | 发送幂等键，成功后重新查列表 |
| F8 实验过程 | 轮次、运行编号、状态、调试深度 | `GET /experiments/{id}/runs` | `data.runs[]` |
| F8 实验过程 | 时间线、决策摘要、日志和错误搜索 | `GET /experiments/{id}/events` | `data.events[]`、`data.next_cursor` |

| F6 实验提交（预留） | 启动实验 | `POST /experiments/{id}/start` | 仅「待启动」且已绑定就绪主机可启动；返回 `run_id`、`execution_id`、`status` |

## 2. 一次点击怎么取到数据

点知识库中的一条记录时，`KnowledgePage.jsx` 把这条记录的 `document_id` 交给 `knowledge/api.js`。它请求 `kb/entries/{id}`。公共的 `shared/api.js` 加上接口前缀、发送请求、检查响应，再把 `data` 交回页面。

默认完整路径是 `/evoresearch/api/kb/entries/{id}`。如果 DSH 部署在 URL 子目录下，默认前缀跟随该目录。后端的地址有变化时，在页面的「接口设置」修改同源前缀。具体字段或路径变化时，改对应功能目录的 `api.js`。

所有普通接口都按 `{code, message, data}` 读取。`code=0` 表示成功。请求失败时显示后端的 `message`，接口返回网页时提示接口未接入。数据数组为空且请求成功时才显示空列表。

## 3. 列表、详情、曲线的数据样子

知识条目列表的每项有 `document_id`、`type`、`title`、`source_type`、`source_id`、`created_at`。详情加上 `content` 对象。论文摘要的类型是 `paper_summary`，实验报告是 `experiment_report`。正文键名由后端定义，页面完整展示返回的对象。

指标返回 `series[]`。每组有 `runId`、`candidateId`、`split`、`name` 和 `points[]`。点包含 `epoch`、`global_step`、`value`、`seed`、`recorded_at`。图表按指标和数据划分分组，再按运行和种子分成不同曲线。横轴优先使用全部数据都具备的 `epoch`，其次使用 `global_step`。缺少统一坐标时，仍可在原始数值表中查看数据。

## 4. 实时更新和终止怎么显示

页面先把历史事件分页读完，再把最大的 `seq` 作为 `since` 建立 SSE 连接。重连交给浏览器的 `Last-Event-ID`，服务端应优先使用它。页面按序号去重和排序，切换任务时会关闭旧连接。事件持续到来时，最多约每秒刷新一次轮次、指标、候选和任务状态。

终止按钮调用后端后，页面读取任务详情，并每三秒核对一次状态，直到任务进入「已终止」或「已完成」。请求报错后也会继续核对，以处理请求已送达、响应却中断的情况。显示的任务状态取自后端。

## 5. 联调要找谁

张嘉荣提供 F4 的列表、详情、编辑和删除路由。马雨瑶提供实验提交、任务、轮次、事件、SSE、指标、候选、认证、终止和状态查询路由。邓玲提供图谱查询与节点详情。胡语晨的界面子系统后端提供预警规则的读写、触发判定和通知。

业务模块应把接口注册到同一个 DSH Web 中，并按宿主身份检查权限。当前前端插件的 `src/host.js` 只负责安装客户端模块。页面首次只装此包时，会显示接口未接入，接入业务后端后再联调真实结果。

实验提交与图谱的接口细节、未接入的边界，以及本地调试的数据隔离见[新增接口设计](新增接口设计.md)。
