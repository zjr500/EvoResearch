# 第六周开发工作安排（11月30日—12月6日）

**统一交付时间：12月6日22:00（北京时间），本周仅此一个交付节点。** 在第五周成果基础上完成剩余业务功能及必要的模块联调。业务范围以最新版《EvoResearch_需求分析.pdf》UC01—UC14 为准，各成员职责边界与协作规则同《第五周开发工作安排》。

## 一、本周目标

完成全部 14 个用例的业务实现：实验异常处理、单轮详情、候选方案、测试集认证、实验报告生成与回流，以及实验过程可视化界面；完成 UC01—UC03、UC13、UC14 的联调收尾。

## 二、按成员的具体任务

### 张嘉荣：知识库后端与集成

1. 完成 **UC01** 剩余业务收尾及正式联调，确认事件实际消费状态可查。
2. **UC12** 报告发布、自动入库及知识同步：保证来源唯一，发布失败重试不产生重复条目，KB 可查并触发索引/图谱同步。
3. 完善知识索引、增量更新及失败恢复。
4. 处理跨模块共享基础设施问题，统一检查迁移兼容性。

**交付**：UC01 联调记录、报告发布与回流代码及迁移、索引恢复测试；提供报告发布接口及样例供第七周对接。

### 马雨瑶：自主实验后端

1. **UC07** 实验异常检测与记录、用户响应、复检恢复/终止；复检成功才恢复，失败保持暂停，未解决不继续实验，可转停止。
2. **UC08** 单轮实验详情查询：每轮方案/过程/结果/结论可查；未结束的轮次只显示已产生信息；跨任务/跨 owner 拒绝。
3. **UC09** 候选方案登记、比较、选择及取消：仅 completed 轮可选，重复登记不重建，认证前可取消且 run 保留，认证后禁止改集合。
4. **UC10** 独立测试集认证：冻结代码/权重/数据/协议并验证哈希；无标签预测与可信评分；部分失败不公布任何测试结果，仅重试未完成项，全部结束后统一公布；必须有主要业务实现及负向测试，不交空壳。
5. 完善实验运行、停止及认证的自动化测试。
6. 提供报告生成所需的完整实验事实，事实可追溯。

**交付**：UC07—UC10 业务代码与迁移、认证负向测试、实验事实接口、真实/Mock/未验证清单。

### 胡语晨：全部新增业务界面

1. **UC06** 实验过程、实时日志、进展及指标可视化；断线重放不重复，不提前显示测试分数。
2. **UC07** 异常现象/原因/建议/用户响应/处理状态界面；不另写恢复引擎。
3. **UC08** 单轮实验详情界面。
4. **UC09** 候选方案比较、选择及取消界面。
5. **UC10** 认证过程及统一公布后的结果展示。
6. **UC11** 停止实验交互：确认/取消停止、等待实际退出、失败或未知状态提示。
7. **UC12** 实验报告展示界面；完成 UC01—UC05、UC13/14 与第五周已交付后端的联调。第六周新增后端先用约定样例开发，第七周切换真实接口。

**交付**：上述页面业务代码、客户端契约/交互测试、真实运行截图和演示步骤。

### 邓玲：知识图谱、报告与科研对话后端

1. **UC12** 实验报告生成与查询：根据真实实验事实生成报告；遵守终态门禁，无候选也可出报告，一任务一份报告。
2. 对接报告发布及自动回流知识库功能（张嘉荣提供发布/入库服务）。
3. 完善知识图谱及科研对话功能，完成 UC03/13/14 联调收尾。
4. 完成所属模块的必要联调与测试。

**交付**：报告生成/查询后端及测试、回流接口适配、图谱与对话功能的完整测试。实验事实未就绪时使用统一事实 fixture 完成报告主要逻辑，第七周切真实数据，不把 fixture 报告当真实实验产出。

## 三、协作与质量要求

沿用《第五周开发工作安排》第四节全部要求，特别强调：

1. 本周为业务开发最后一周，UC07—UC10、UC12 的主要业务实现及独立测试必须本周完成，不整体拖到第七周。
2. 联调以第五周已交付接口为基础；第六周新增功能不要求其他成员提前交付，按约定样例独立开发，周末统一交接，第七周完成真实对接。禁止各自新增兼容私有字段。
3. 报告和认证不得越过安全与业务门禁赶进度；真实 E2E 受上游影响时仍须交实际业务代码与独立测试，并准确标记"联调未完成"。

## 四、第六周末交接（供第七周使用）

马雨瑶交付异常、轮次详情、候选、认证及报告所需实验事实接口；张嘉荣交付报告发布和知识同步服务；邓玲交付报告生成与查询接口；胡语晨交付所有业务界面及调用适配。各自附真实/Mock 验证记录，未联调项列入第七周验收，不以同周其他成员提前提交为前提。
