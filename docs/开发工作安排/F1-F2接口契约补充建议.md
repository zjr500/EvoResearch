# F1/F2 接口契约补充建议（周日审核稿）

2026-11-20。依据项目立项 v3.0、需求规格 v2.1、接口/数据库 v1.2 和第四周安排。本文记录用户授权先行实现的最小补充，不替代冻结契约。技术说明仓库文件仍标 v1.1、配套清单标 v1.2；依赖继续沿用已验证安装，不按旧表升级或降级。

## 接口与流程

统一 JSON `{code,message,data}`；所有写请求携带非空 `idempotency_key`（最多128字符）。写操作返回 HTTP 202 与 operation_id、status，轮询操作直到成功/失败。错误 4001 参数、4004 不存在/非归属、4009 状态、4020 幂等冲突；新增5000本地处理或模型失败。

| 方法及路径 | 入参/返回 | 依据与补充 |
|---|---|---|
| POST /papers | pdf_base64；异步返回操作记录 | F1新增；JSON base64，PDF上限20MiB，请求上限28MiB，不接受服务器文件路径 |
| GET /papers/{id} | 论文元数据与状态，不返回文件路径/全文 | F1新增 |
| PUT /papers/{id} | title/authors/year/abstract；确认或补全 | F1新增；确认要求非空title，其余可空；状态转已入库 |
| POST /papers/{id}/summary | 只含幂等键 | F2新增；仅已入库可生成 |
| GET /kb/entries | type、keyword、cursor、limit | 沿用冻结字段；entries/nextCursor，稳定entry_id倒序游标，默认20，上限100 |
| GET /kb/entries/{id} | document_id、type、title、content、source_type/source_id/created_at、user_note | 沿用冻结主体字段 |
| PUT /kb/entries/{id} | title/user_note白名单 | 本周普通编辑；embedding失效，indexed=false；不伪称完成F3索引 |
| GET /kb/operations/{id} | 状态、result、error_code/error_message | 临时知识库命名空间，避免占用共享 /operations/{id} |

不实现报告回流POST /kb/entries、F3语义检索、F4删除或其他成员业务。摘要content固定method/datasets/conclusions三个非空字符串，未知信息由模型注明未报告；source_type=paper，source_id指向原论文。

## 用户隔离与DSH

复用DSH 0.2.1-rc.2 connection.admit的已认证peer；不信任请求体、query或自造header的用户ID。当前宿主浏览器principal只有本机owner，该本机数据库映射owner=1；其他principal拒绝403，不猜测身份字段。数据库和服务层支持多个owner，已测试隔离，但没有声称单个当前DSH浏览器提供多账号。将来如DSH提供多用户principal，需补可信身份映射。多用户部署前不能复用固定owner映射。

同一owner内容哈希去重；不同owner生成独立论文与存储路径，避免泄露别人记录。所有查询、确认、摘要和条目编辑按归属过滤。客户端归属字段拒绝。旧全局hash唯一约束通过002迁移改为UNIQUE(uploader_id,content_hash)。

## 数据库与状态

001保留旧papers建表，002由migrateKnowledge事务执行，迁移版本记在knowledge_migrations，可重复启动；保留旧paper_id和元数据。新增papers.full_text、parse_error、created_at。已有未知kb_entries结构时拒绝自动改表，要求协调，防止覆盖组员表。

有效PDF先建立待确认记录；解析失败保留待补全记录，失败操作result带paperId；非PDF不建Paper、paperId=null。不可靠元数据留空，title/author优先PDF信息字典，其次显式Title/Authors文本；年份只取显式Year/Published，不把文件创建日期当发表年份。无文本可用时允许用户补abstract后生成，并明确这是基于用户提供摘要。

kb_entries采用冻结主要字段和UNIQUE(source_type,source_id)。重新生成成功后覆盖同一条目；调用失败或结构校验失败不新增、不覆盖旧条目。embedding暂留NULL，不提前实现第五周F3。

当前仓库无共享operation_records迁移。本实现不创建/改写该表，临时使用knowledge_operations，影响范围仅知识库。字段含owner_id、幂等键、操作类型、请求摘要、状态、结果JSON、错误码/脱敏错误、时间戳。UNIQUE(owner_id,idempotency_key)；请求摘要包含路径/操作/规范化请求，PDF使用内容哈希。重试返回同一operation_id和当前状态；键相同内容不同返回4020。失败重试用新键。重启将未完成的本地操作标失败，不擅自重放模型调用。

周日须与共享基础设施负责人协调：统一operation_records的owner字段、键作用域、结果/错误存储及路由分发，再迁移本地记录。当前没有创建第二份同名共享表。已记录行为差异：普通编辑目前也异步受理；备注不参与未来向量化；条目更新返回indexed=false；知识操作查询临时命名空间。

## 运行边界

进程内执行器，不引入队列；操作先持久化再执行。解析为文本PDF，不含OCR。20MiB PDF、摘要输入20万字符、输出10万字符限制；模型收到120秒AbortSignal。真实模型由DSH已有凭证管理，无插件密钥存储。服务错误不回显provider凭证或原始异常。
