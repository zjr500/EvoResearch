## 五、PR 统一要求

每人本周至少一份可审阅的 PR，标题格式：`[第4周][F1-F2] 论文导入与摘要初版`（替换成自己的模块）。

PR 包含五样：

1. **代码**：本周负责的功能，以及本周用到的建表脚本
2. **测试**：至少一项可复现的验证，附运行命令和输出
3. **说明**：怎么安装、启动、验证；用到的接口或模拟数据注明来源
4. **证据**：截图或脱敏日志
5. **交接**：对应的 v1.0 接口、未完成项、下周谁会用到

**不提交：** 真实密钥和 Token、SSH 私钥、`node_modules/`、`.db` 文件、模型权重、未脱敏日志。
