# 第五周开发工作安排（11月23日—29日）

**统一交付时间：11月29日22:00（北京时间），本周仅此一个交付节点。** 统一代码基线：组长发布的最新统一骨架提交（以发布通知中的提交号为准）。业务范围以最新版《EvoResearch_需求分析.pdf》UC01—UC14 为准。

总体节奏调整为：第五周、第六周业务开发，第七周系统集成与测试。各成员以需求分析、实际代码和每周开发工作安排为依据，自行完成所属模块的设计及实现；不再提前编写详细接口契约和数据库设计文档。跨成员接口由提供方负责实现和维护。每周只在统一截止时间交付；本周不得将其他成员尚未交付的功能作为开工或验收前提。调用方依据已有公共服务、需求和约定字段自行编写测试数据，下周再切换本周新增的真实接口。

## 一、本周目标

完成核心业务及下游依赖功能：知识库管理与检索、知识图谱、科研对话、AI 自主实验核心链路、知识库界面与统一工作台，为第六周候选/认证/报告及实验可视化打好基础。

## 二、按成员的具体任务

### 张嘉荣：科研知识库后端与共享基础设施

1. **UC02** 知识库查询、编辑、删除、受鉴权原文读取；保持用户隔离与并发版本，越权拒绝。
2. 实现真实语义检索、索引建立及增量更新；更新/删除后索引及时失效，检索结果必须带来源。
3. **UC04/05/13/14** 提供同一个公共知识检索及指定条目读取服务，供实验和科研对话模块使用；不按调用方复制实现。
4. **UC03** 提供知识入库、修改、删除事件的持久消费能力（claim/ack/fail），供知识图谱模块使用。
5. **UC01** 修复论文解析及摘要生成质量问题，完善已有后端；使用真实 PDF 验证，前端按现有接口独立开发。
6. 负责必要的共享基础设施维护、迁移验收；补齐真实 DSH Agent 工具隔离验证，不重复开发实验业务。

**交付**：UC02 业务代码与迁移、真实检索记录、公共检索/读取服务与事件消费接口、自动化测试及运行结果。

### 马雨瑶：AI自主实验核心功能

1. **UC04** 研究任务定义、任务配置后端、数据集划分依据、指标/最大轮数、实验独立模型配置及环境检查；已有测试集沿用不重分，不可用配置保留旧值。
2. **UC05** 复用现有 Docker 执行器与实验 Agent 服务，完成实验方案生成、代码修改、真实训练、验证反馈及多轮循环；至少两轮受控方案/修改/训练/验证反馈，轮数上限有效；不重新实现 DSH Agent/jobs。
3. **UC06** 实验方案、日志、进展、指标的记录及查询服务；断线重放不重复，重启后记录保留，不提前暴露测试分数。
4. **UC11** 实验终止业务：确认后禁止新轮，实际停止容器并确认父子进程退出，已有 run/候选/事实保留，超时不伪报成功。
5. 保存完整实验事实，为第六周实验可视化、候选方案、认证和报告生成提供基础。
6. 停用 SSH 路线，不再进行额外技术调研。

**交付**：任务配置 API、实验业务表迁移、多轮实验编排、真实训练/日志/停止证据、编排与隔离负向测试、各用例真实/Mock/未验证清单。真实模型未获授权时用 Mock 验证编排，但真实训练应独立运行，二者不能混为自主 AI 验收。

## 四、协作与质量要求

1. 不设置每日检查点、每日汇报或中途强制交付节点；每周只有统一交付时间。
2. 遇到上游尚未完成的情况，先使用明确标记的测试数据开发，之后完成真实对接；遇到重大阻塞及时沟通。
3. 每周交付必须包含实际业务代码、必要的自动化测试及运行结果，不接受仅提交接口设计、技术调研或占位页面；Mock 测试通过不等同于真实业务验收通过，真实/Mock/未验证边界须如实标注。
4. 新增数据库迁移遵循仓库现有迁移机制，业务模块在 `migrations/modules/<模块>/` 按连续编号新增 SQL，现有机制自动扫描；知识库内置迁移由张嘉荣维护。其他人不争改公共迁移、根入口与锁文件；不重复创建 operation_records、身份/模型/任务等公共框架。
5. 提交前执行 `npm.cmd run check`、`npm.cmd run build`、`npm.cmd test`；保留现有全部测试断言，必要调整需说明业务原因，不删/skip 掩盖失败。
6. 秘密、真实 .env、凭证、数据库、日志、临时验收页面、node_modules/dist/模型权重不进源码；真实运行使用独立 DB/profile；无授权不调用付费模型。
7. 每人在自己的开发分支保留真实、可审查的开发提交；统一截止时提交 PR，不要求提前交付。PR 标题建议 `[第5周][UCxx-UCyy] 具体功能`，注明 BASE_SHA 和真实/Mock 边界。
