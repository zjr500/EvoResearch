## 安全与排错

- 不打印环境变量全集、Key、Cookie、登录 URL 中的 Token；不访问私有凭证文件。
- 模型选择器不可见：检查 DSH Key 保存状态、Provider 和模型配置，不修改 EvoResearch 凭证逻辑。
- F2 半配置：清除终端旧的覆盖环境变量，并确认 .env 两个覆盖项都空或都有值。
- 模型不可用或鉴权失败：修复 DSH 配置，使用新的幂等键重试；插件不会自动换模型。
- git check-ignore .env llm-api_key.txt；提交前核对 git diff --cached。不要强制添加忽略文件。
