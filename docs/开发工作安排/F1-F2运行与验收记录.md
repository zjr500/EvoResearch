## 安装和启动

在仓库根目录使用Node.js >=22.19.0：
```powershell
npm ci
npm run check
npm run build
npm test
$env:EVORESEARCH_DB_PATH = './data/evoresearch.sqlite'
$env:EVORESEARCH_SUMMARY_PROVIDER = '<DSH已配置provider>'
$env:EVORESEARCH_SUMMARY_MODEL = '<该provider可用model>'
dsh plugin --profile web add .
dsh web --no-open
```

## 已实际完成的验证

真实Node/SQLite/PDF解析：有效PDF的标题、作者、年份、摘要；无效文件拒绝；损坏PDF待补全；元数据补全；同用户去重和跨用户隔离。测试使用动态生成的合法PDF，不是替换解析器；原有sample.pdf另在真实宿主验证中使用。

DSH 0.2.1-rc.2真实宿主与HTTP：隔离profile、临时数据库；未登录返回401，登录后PDF上传、确认成功；未配置模型时操作失败且entries=0。第二次在DSH官方llm/stream事件中注入显式Mock provider，摘要操作成功且entries=1。真实注册、认证、HTTP、SQLite及模型适配调用链路均执行；外部大模型网络调用未执行，不能以Mock结果宣称模型质量或凭证验证通过。
