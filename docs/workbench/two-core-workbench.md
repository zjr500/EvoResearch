# 双核心科研工作台

2026-10-29。此变更仅整理前端与交互，后端 API、实验执行和 Graphiti 架构不变。

## 布局与入口

移除旧 main 页面和左侧平级科研导航，使用 DSH `sidebarRightTabs` 注册 EvoResearch，并在 `sidebar.right.pane.tab` 中渲染。顶部 `conversation.header.leading` 提供 EvoResearch 模式状态和启用/关闭入口，左侧 `sidebar.footer.action` 提供返回科研工作台入口；不覆盖原生右栏收起/展开按钮。左侧导航和中间对话由 DSH 管理。面板宽度、折叠、展开和窄屏行为均由原生右栏管理。面板 keepMounted 保留切换状态。

项目选择与新建位于公共上下文栏，不占一级模块。一级导航只有：

- **AI 自主实验**：创建实验、历史与监控；选中任务后展示执行监控、指标分析、结果对比。创建成功跳入对应 run。对比筛选同模板、指标方向和预算的记录，并提示核对数据划分/种子；不夸大知识增强收益。
- **自进化科研知识库**：检索与知识、文献与 PDF、关系探索。统一显示论文和实验来源，支持 Zotero、PDF 上传、逐页文字阅读、哈希追溯与 Graphiti 图谱。

知识同步是后台过程：实验详情展示同步状态和失败重试，知识库展示更新动态，没有独立知识回流入口。

## 上下文联动

实验详情 → 查看相关知识：保留项目和 run ID，进入知识库并筛选该实验的更新记录；可返回同一实验详情。知识更新和检索命中的实验来源 → 打开实验详情。图谱节点与已加载 episode ID 存在明确关系时提供来源与实验跳转，不猜测没有来源映射的节点。

项目切换清空旧实验选择、比较项和来源筛选；异步检索和图谱响应不得覆盖新项目。未在当前加载范围内找到的实验给出提示，不伪造详情。后台列表原有数量限制保持不变。

问答复用 DSH 会话：检索命中可携带问题和来源创建原生会话草稿，由用户发送。右侧没有第二套消息流。

## 图标与验收

使用 DSH ui-primitives 原生图标：思考/知识树用于两大模块，新增、列表、搜索、文档、分支、刷新、链接用于内部视图与操作。图标旁保留短标签；状态保留文本。没有引入装饰性渐变或另一套图标主题。

自动测试覆盖原生右栏注册、两模块导航、图标组件，以及实验→知识→实验的状态跳转；属于组件/契约验证，不是浏览器点击验收。

用户本机检查：点击顶部 EvoResearch 启用模式（新环境先选择 DSH 工作区）；观察三栏、拖动分隔线、收起再展开；创建/选择任务并切换监控、分析、对比；查看相关知识并返回；同步文献、打开 PDF 分页；检查浅色/深色、窄屏及键盘操作。视觉与真实点击仍待用户验收。

## 0.8.0 本机模式修复

默认安装和启动均不依赖 Docker。Neo4j/APOC 离线时显示服务连接异常及知识数据库未连接提示；原有历史状态是已保存记录，不代表当前在线检索成功。模式偏好只保存启用标记，不存访问码。关闭模式不停止后台进程；收起右栏不改变模式。全新环境尚未配置 DSH 工作区时需先在原生页面选择工作区，再打开面板。

2026-10-29 已通过真实 IAB 点击验证：首页入口、开启/关闭、双模块切换、右栏收起、自动化页面与插件页。宽度拖动、深色/窄屏、Skills 和完整实验交互仍待进一步验收。
