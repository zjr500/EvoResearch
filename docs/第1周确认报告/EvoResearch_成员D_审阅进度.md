# EvoResearch 产出与关联子系统初步技术报告（成员D）
项目：EvoResearch 基于 DeepSeek Harness 的AI自主实验与自进化知识库插件
负责功能：F10实验报告自动生成与回流、F11文献知识图谱、F12知识库增强对话

## 一、子系统简介
产出与关联子系统是实现项目**知识自进化闭环**的核心模块。主要承接自主实验子系统输出的实验结果，将其转化为知识库可识别的知识条目；同时提供文献与实验报告的图谱可视化；并在DSH对话会话中接入已有知识库，实现问答可溯源。

模块遵循项目协作规范：**禁止直接访问其他子系统数据库**，所有跨模块数据交互均通过预先约定好的REST API完成。本模块只存储自身业务所需缓存数据，原始论文、报告数据统一由知识库子系统维护。

## 二、功能实现思路
### F10 实验报告自动生成与回流
接收自主实验子系统的完成回调，入参包含任务配置、Agent循环步骤记录、SSH执行日志、多轮实验指标、原始反思文本。
1. 原始执行日志内容量大，先做摘要过滤，剔除冗余调试信息，控制输入Token规模；
2. 设计固定格式Prompt，要求大模型输出JSON结构化报告，字段包含：实验假设、实验配置、执行过程摘要、实验结果、核心结论、存在局限性；
3. 增加格式校验与简单重试，若大模型返回非合法JSON，记录日志，最多重试1‑2次，避免无限循环；
4. 将生成的报告封装为知识库子系统规定的文档对象，标记文档类型为`experiment_report`，附带task_id、生成时间等元数据；
5. 调用知识库新增文档API，完成文档入库与向量索引构建，获取返回的`document_id`；
6. 异常处理：大模型超时、知识库接口调用失败时，不破坏DSH整体运行，记录完整错误日志；前端提供**手动重新生成报告**按钮，供用户重试。

### F11 文献知识图谱
以知识库中已入库论文、实验报告作为数据源，构建知识关联图谱。
1. 调用知识库API，批量获取文档列表，拿到`document_id`、标题、文档类型、对应向量；
2. 图谱计算采用**后台异步任务**，不在HTTP同步请求中执行，防止接口超时；计算文档向量之间的余弦相似度，设置相似度阈值，高于阈值则生成“主题相似”关系边，边权重保存相似度数值；
3. 模块本地数据库仅缓存图谱节点、边信息、异步任务状态，不存储完整文档内容；
4. 前端选用G6做图可视化，支持缩放、拖拽；点击图谱节点携带`document_id`跳转至对应文档详情页面；
5. 现阶段仅实现主题相似度关联；论文引用解析作为可选增强，暂不纳入基础版本；增加文档数量上限配置，避免文档过多造成计算压力过大。

### F12 知识库增强对话
基于DSH插件会话钩子实现RAG增强对话，实现对话可引用知识库内容、来源可追溯。
1. 在DSH插件中注册会话事件钩子，维护会话级别的“知识库增强”开关；开关关闭时直接放行原生DSH对话逻辑，本模块不介入；
2. 用户提交提问后，调用知识库语义检索接口，召回多条相关文档片段；
3. 将检索得到的片段整理为参考资料，拼接到Prompt上下文，再交给DSH原有推理链路；
4. 大模型输出回答后，追加来源标注，关联对应`document_id`，前端渲染可点击链接，跳转查看论文或实验报告；
5. 降级逻辑：知识库检索接口异常、超时，直接跳过检索，使用原生对话返回结果，同时在界面给出提示，不阻断用户聊天。

## 三、模块分层与外部依赖
1. **接口接入层**：对外提供REST接口，接收实验完成回调、前端页面请求，注册DSH插件生命周期与会话钩子；
2. **业务逻辑层**：报告生成处理、图谱异步任务调度、RAG上下文组装、异常与重试逻辑；
3. **外部调用层**：调用大模型API、知识库子系统API；接收自主实验子系统回调；
4. **数据层**：只保存图谱任务状态、节点‑边缓存，不重复存储文档正文。

外部依赖：DeepSeek‑Harness SDK、知识库子系统REST API、大模型HTTP API、前端G6可视化组件。

## 四、主要风险与预案
1. Token消耗过高：对原始实验日志做摘要裁剪；报告生成设置Token上限，防止大模型消耗爆炸；
2. 图谱计算耗时：采用异步任务，前端轮询任务状态；配置最大处理文档数量；
3. DSH插件接口变动：锁定项目约定的DSH基线版本，跟进上游更新日志；严格遵守第2周冻结的跨模块接口契约；
4. 下游服务调用失败：全部外部调用增加超时、异常捕获，记录日志，提供手动重试入口，做好功能降级。

## 五、开发实施步骤
1. 搭建DSH插件子模块骨架，编写本模块对外API简要文档，对齐和知识库、自主实验子系统的接口；
2. 优先开发F10：对接实验完成回调，完成报告生成逻辑，调通报告回流知识库整条链路；
3. 开发F12知识库增强对话：对接DSH会话钩子，实现检索注入、来源标注，完成对话侧基础能力；
4. 开发F11知识图谱：实现异步相似度计算，输出图谱JSON数据，对接前端可视化组件；
5. 端到端联调：和另外两个子系统联调，测试正常流程以及各类异常场景；
6. 完善日志，修复缺陷，完成模块自测。
